The bookmarklet only works if the browser allows it and the player uses a compatible video element. Edgenuity may block it or use a player it cannot control. It does not unlock lessons, skip required work, or change course progress.

Set up the speed bookmark on Chrome

  1. Choose a speed above, then press Copy video-speed bookmarklet.
  2. In Chrome, show the bookmarks bar with Ctrl + Shift + B.
  3. Right-click the bookmarks bar and choose Add page (or Bookmark manager → Add new bookmark).
  4. Name it Set video speed. Paste the copied text into the URL field and save.
  5. Open your lesson video. If allowed, click the bookmark to try setting the video speed.
If your school manages Chrome and blocks bookmarklets or bookmark editing, don't try to bypass its controls. Ask your teacher or school IT whether an approved playback-speed option is available.
